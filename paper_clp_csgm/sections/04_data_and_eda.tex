\section{Data and exploratory analysis}
\label{sec:data_eda}

We evaluate two F3 settings. In the first, clay volume is reconstructed in a
held-out well. In the second, porosity in one well is reconstructed from
gamma ray alone.

\subsection{Field settings and benchmark provenance}
\label{subsec:field_settings}

The experiments use the processed F3 well-log curves of
\citet{zhang2025rockphysicslogs}; no new field data were acquired. We use the
FS2--FS6 intervals of F02-1, F03-2, F03-4, and F06-1. Sonic and gamma ray are
available in all wells; density is measured in F02-1/F03-2 and predicted in
F03-4/F06-1. The processed porosity target is density-derived, whereas
$V_c$ denotes the dimensionless clay-volume fraction estimated from gamma
ray using the Larionov relation; further geological and processing details
are given in the source study.

The cross-well benchmark reconstructs $V_c$ using processed F3 well-log
tables associated with the dataset of \citet{zhang2025rockphysicslogs}, with
F02-1, F03-2, and F06-1 used for development and F03-4 held out for testing.
Zhang et al.\ report an experimental condition with an SNR of 30 but do not
specify its mathematical definition or explicitly state whether it is
expressed in decibels. We retain the designation \texttt{30dB} used in the
input filenames for consistency and reproducibility, without interpreting it
as an independently verified signal-to-noise ratio. The single-well
benchmark reconstructs F03-4 porosity using gamma ray as the only dense
input. In both benchmarks, sparse target observations are generated by
coordinate subsampling of the corresponding processed target curve.
Appendix~\ref{app:lapa_case} provides a limited-sample Lapa permeability case
based on \citet{alvarez2025nonlinear}.

\paragraph{Channel-target correlations and input design.}
Table~\ref{tab:eda_correlations} reports descriptive Pearson correlations used
only to guide input design. Clay volume in this benchmark is computed from
gamma ray through the Larionov relation
\citep{zhang2025rockphysicslogs}; including gamma ray would therefore expose
the model to the log from which the target was derived. The main cross-well
input instead uses sonic, density, acoustic impedance, and $V_p$. The
gamma-ray index is linear between the clean and shale endpoints, whereas the
Larionov transformation from that index to clay volume is nonlinear. In a
fully logged well the relation can be evaluated directly, so the proposed
model is not intended to replace it. Gamma ray is restored only in
Appendix~\ref{app:crosswell_gr_embargo} to assess the effect of that channel.

In F03-4, sonic travel time follows the processed porosity almost one to one,
whereas gamma ray is only weakly related to it. Sonic is left out for that
reason. The density curve behind this porosity was itself predicted from sonic
and gamma ray. The test that remains uses gamma ray as the only dense log and
keeps a few values of the porosity curve as measurements. It is not a porosity
interpretation from density, neutron, and sonic together
(Fig.~\ref{fig:eda_f03_profile}).

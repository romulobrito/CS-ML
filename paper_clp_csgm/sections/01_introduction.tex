\section{Introduction}
\label{sec:introduction}

Petrophysical target-log reconstruction builds a continuous property profile
in a target well. Dense wireline logs run along the well, but they measure
the target property only indirectly
\citep{ellis2007well,asquith2004basic,wang2024loggingreview,mondal2022corelog,sun2026corecalibrated}.
A few depths already carry a value of that property. The task is to
reconstruct the remaining depths while keeping those known values.

Supervised regressors learn a nonlinear map from logs to the target property.
When the sparse observations are available, they are commonly joined to the
dense logs and used as extra inputs
\citep{bishop2006pattern,ahmadi2019comparison,wood2020predicting,pan2023multiwell,mondal2022corelog,koray2024integrated,matinkia2023permpred,abdelazim2022permlogs,shi2024gnsperm,he2025porosity,markus2026hybrid}.
After training, that map is not required to reproduce the observations it was
given. In this work those observations stay measurements: the reconstructed
window has to match them.

Recent studies complete a missing log interval, translate a geomodel property
map, or regress porosity and shale volume from the log suite
\citep{koeshidayatullah2026timegpt,alfakih2026pix2geomodel,alfakih2025wellloggan,alfakih2023northsea}.
Each of those predictors returns the missing property from a trained map.
Section~\ref{sec:related_work} compares those trained maps with the
measurement constraint used here.

Enforcing that match still requires a representation of the target window.
A fixed sparsity basis is a weak description of this window when the logs
change from one well to another
\citep{donoho2006compressed,candes2006robust,candes2006stable,bora2017compressed}.
Conditional Latent-Prior CSGM (CLP-CSGM) learns which target windows the
decoder can produce and lets the dense logs set the starting point of the
search. At inference the search stays near that point, and the decoded window
must agree with the sparse measurements.
Section~\ref{subsec:test_time_reconstruction} states this step. Ridge is the
primary reference for the map from dense logs to that starting point, because
it is a linear low-capacity map, not because it is best in every regime. An
MLP is tested with the same pipeline.

The contributions are threefold. First, the dense logs set the starting point
and the sparse values stay measurements that the reconstructed window must
match. Second, the objective has a MAP/Tikhonov reading and a local error
bound that separates decoder error, a poor starting point, noise, and whether
nearby windows can be told apart from the measurements. Third, the tests use
three development wells and hold out F03-4. They compare direct baselines,
versions that drop the starting point or the measurement match, and a ridge
map against a multilayer perceptron for the starting point. That local bound
separates those error sources under stated assumptions. It is not a verified
S-REC guarantee for the trained decoder.

\section{Introduction}
\label{sec:introduction}

Petrophysical target-log reconstruction builds a continuous property profile
in a target well. Dense wireline logs run along the well, but they measure
the target property only indirectly
\citep{ellis2007well,asquith2004basic,wang2024loggingreview,mondal2022corelog,sun2026corecalibrated}.
A few depths already carry a value of that property. The task is to
reconstruct the remaining depths while penalizing disagreement with those
known values.

Supervised regressors learn a nonlinear map from logs to the target property.
When the sparse observations are available, they are commonly joined to the
dense logs and used as extra inputs
\citep{bishop2006pattern,ahmadi2019comparison,wood2020predicting,pan2023multiwell,mondal2022corelog,koray2024integrated,matinkia2023permpred,abdelazim2022permlogs,shi2024gnsperm,he2025porosity,markus2026hybrid}.
After training, that map is not required to reproduce the observations it was
given. In this work those observations stay measurements: the reconstructed
window is penalized for disagreeing with them, and that penalty does not
force every observation to be met exactly.

Recent studies complete a missing log interval, translate a geomodel property
map, or regress porosity and shale volume from the log suite
\citep{koeshidayatullah2026timegpt,alfakih2026pix2geomodel,alfakih2025wellloggan,alfakih2023northsea}.
Section~\ref{sec:related_work} compares these approaches with the explicit
measurement-fidelity formulation considered here.

Using that penalty still requires a representation of the target window.
A fixed sparsity basis is a weak description of this window when the logs
change from one well to another
\citep{donoho2006compressed,candes2006robust,candes2006stable,bora2017compressed}.
Conditional Latent-Prior Compressed Sensing with Generative Models
(CLP-CSGM) learns which target windows the
decoder can produce. The conditional map predicts a latent code
$\boldsymbol{z}_0$ from the dense auxiliary logs. This code provides an
informed initialization and serves as the reference for the quadratic penalty
during latent refinement. Latent refinement balances agreement with the sparse
observations against deviation from $\boldsymbol{z}_0$. A residual at the
observed depths can remain. The decoder range and that penalty are separate:
the range limits which windows can appear, and the penalty keeps the latent
code near $\boldsymbol{z}_0$.
Section~\ref{subsec:test_time_reconstruction} states this step, including the
first trajectory and the perturbed restarts. Ridge is the
primary reference for the map from dense logs to $\boldsymbol{z}_0$, because
it is a linear low-capacity map, not because it is best in every regime. A
multilayer perceptron (MLP) variant is compared under the same channels and
the same split.

The contributions are threefold. First, the dense logs predict
$\boldsymbol{z}_0$, which initializes the first latent trajectory and remains
the center of the quadratic penalty, while the sparse values enter as a
penalized measurement residual. Second, the objective has a maximum a
posteriori (MAP)/Tikhonov
reading and a local error bound that separates decoder error, a code
$\boldsymbol{z}_0$ far from a good code, noise, and whether
nearby windows can be told apart from the measurements. Third, we characterize
the regime-dependent behavior of the proposed reconstruction in a controlled
cross-well benchmark, using three development wells and F03-4 as the single
held-out test well. We compare the proposed method against direct predictors
and examine the separate contributions of the conditional prior and
sparse-measurement refinement through ablation studies. We also assess the
influence of training support, measurement availability, and latent-prior
architecture.

CLP-CSGM has lower mean root mean square error (RMSE) than the direct
autoencoder in seven of the
nine cross-well cells, and those gains concentrate where training support is
smallest. Other comparators can have lower error in the same grid. With only
F03-4 held out, these results stay inside that benchmark and do not establish
general cross-well robustness or operational transferability. The local
recovery bound remains conditional and does not certify the set-restricted
eigenvalue condition (S-REC) for the trained decoder.
